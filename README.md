# Hospital-Emergency-Room-Operation
# 🏥 Hospital Emergency Room Analytics Dashboard

This project demonstrates an end-to-end healthcare analytics workflow using **Power BI, Power Query, DAX, and Excel** to analyze Emergency Room (ER) operations and generate actionable insights. The dashboard helps monitor patient flow, waiting time, satisfaction levels, admissions, referrals, and operational performance to support data-driven healthcare decisions.

---

# 📌 Project Overview

The objective of this project is to transform raw hospital emergency room data into meaningful business intelligence through data cleaning, analysis, visualization, and reporting.

### ✅ Data Cleaning & Transformation (Power Query)
- Cleaned and transformed raw hospital data.
- Prepared the dataset for analysis and dashboard development.

### ✅ Data Analysis (DAX & Power BI)
- Analyzed patient visits, waiting time, admission status, referrals, demographics, and satisfaction scores.
- Created dynamic KPIs and calculated healthcare performance metrics using DAX.

### ✅ Interactive Dashboard (Power BI)
Built a four-page interactive dashboard featuring:
- Monthly View
- Consolidated View
- Patient Details
- Key Takeaways

Included dynamic filters, KPIs, patient demographics, referral analysis, and operational performance metrics.

### ✅ Business Insights
- Monitored patient volume and average waiting time.
- Analyzed admission rates and department referrals.
- Evaluated patient satisfaction and demographic distribution.
- Identified peak hours and busy days to support resource planning and improve emergency room efficiency.
